# PySbagen Current Product Priority

**Date:** July 31, 2026  
**Status:** Active ordering decision

## Current priority

Before implementing the documented Creative Cycle product, PySbagen will address the I-Doser and SBaGen pain points recorded in:

- `docs/research/IDOSER_SBAGEN_PAIN_POINT_SCOUT.md`

The immediate direction is compatibility, preservation, inspection, and ordinary-user reliability around the existing I-Doser/SBaGen lineage.

## Creativity status

## Next compatibility questions

The next product work should begin from the pain-point scout, especially:

1. an honest SBG/DRG import report;
2. preservation of DRG metadata and package elements;
3. a full original-SBaGen semantic compatibility matrix;
4. timeline/source inspection before playback;
5. audio-path qualification;
6. local-first library and provenance.

No creativity feature work should start until this priority is explicitly changed.
