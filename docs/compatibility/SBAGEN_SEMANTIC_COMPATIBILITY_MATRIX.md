## Interpretation rules

- **supported** means the current parser and renderer preserve the intended semantics covered by fixtures.
- **equivalent** means PySbagen represents the construct differently but expects equivalent behavior. It remains visible in reports without blocking ordinary rendering.
- **partial** and **approximated** require visible acknowledgement before rendering.
- **unsupported**, **unknown**, and **missing-source** remain inspectable and preservable but do not produce a complete render claim.
- **unsafe-to-render** blocks rendering.
- **intentionally-excluded** covers understood legacy controls that do not belong in a modern cross-platform audio engine.

## Fixture provenance

All committed fixtures are synthetic, generated by tests, or authored specifically for this repository. No proprietary I-Doser dose is bundled. DRG tests construct a synthetic package from a tiny schedule and synthetic image signature, exercise the known legacy positions, and verify that every element and the original source hash survive preservation.

## Update rule

A row may move to a stronger state only when a fixture proves parser behavior, execution behavior, render policy, and the documented deviation. The tests verify that every row has a valid state and fixture ID and that every row ID appears in this document.
